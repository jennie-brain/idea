# 00. 방법론 — 고객 가치 제안서(Value Proposition Sheet)

> **참고:** [business-analysis-frameworks/08_가치제안서_VPS/00_방법론.md](https://github.com/jennie-brain/business-analysis-frameworks/blob/main/08_%EA%B0%80%EC%B9%98%EC%A0%9C%EC%95%88%EC%84%9C_VPS/00_%EB%B0%A9%EB%B2%95%EB%A1%A0.md)

## 프레임워크 요약

01～07단계가 이미 확보한 근거(산업 구조·KSF·시장 규모·페르소나·기회 우선순위·검증된 Job)를 하나의 문서로 통합해, "이 서비스가 어떤 고객에게 어떤 차별적 가치를 전달하는가"를 확정하는 단계다. 전통적 브레인스토밍형 캔버스 도구 대신, 경쟁사 가치 선언 분석 → 차별적 가치목표 도출 → Value Proposition Sheet 통합의 3단계로 진행한다.

## 이 단계의 문서 구성

| 단계 | 문서 | 내용 |
|---|---|---|
| 1 | [01_경쟁사_가치선언문_분석.md](01_경쟁사_가치선언문_분석.md) | PARK 프롬프트로 잠재 경쟁사 최소 5곳의 비즈니스 규모·BM·전략을 출처와 함께 브리핑하고, 각 기업의 가치 선언문을 도출 |

| 3 | [03_Value_Proposition_Sheet_Claude-Sonnet-5_effort-medium.md](03_Value_Proposition_Sheet_Claude-Sonnet-5_effort-medium.md) | 페르소나·JTBD·경쟁사·차별적 가치·Proof·Job-Feature Map을 하나로 엮은 통합 문서. 07단계 실제 인터뷰 이전의 1차본이며, 인터뷰 결과로 갱신 대상 |

Value Proposition Sheet는 서로 다른 두 벤더사 모델로 각각 산출해 교차검증하며, 산출물 파일명에 사용 모델·Effort Level을 명시한다 — 현재 Claude Sonnet 5(Effort: Medium) 1건만 작성됐고, 다른 벤더사 모델 교차검증은 아직 남아 있다(OQ-55).
